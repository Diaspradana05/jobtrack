# JobTrack

JobTrack adalah aplikasi berbasis AI untuk membantu pengguna mengelola dan melacak proses lamaran kerja secara terorganisir, mulai dari pencatatan lamaran hingga persiapan interview.

## Fitur Utama

- Manajemen Lamaran: Mencatat, mengelola, dan memantau status lamaran melalui tampilan tabel dan Kanban.
- AI CV Matching: Menganalisis kecocokan CV dengan kualifikasi lowongan kerja.
- AI Interview: Simulasi interview, penilaian jawaban, dan laporan evaluasi.
- Agenda dan Pengingat: Mengatur jadwal interview, deadline, dan follow-up.
- AI Assistant: Membantu mengelola data, membuat dokumen, dan membaca file.
- CV Management: Mengunggah dan menganalisis dokumen CV.

## Teknologi

Next.js 14, TypeScript, Tailwind CSS, Supabase, PostgreSQL, pgvector, Google Gemini, Vercel AI SDK, Resend, dan Vercel.

## Keamanan

Menggunakan Supabase Authentication dan Row Level Security (RLS) untuk memastikan setiap pengguna hanya dapat mengakses data miliknya sendiri.
